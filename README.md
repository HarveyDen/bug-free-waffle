# CQC-1 «Ту Казакстан» — мод для Helldivers 2 🇰🇿

Мод заменяет текстуру полотнища оружия ближнего боя **CQC-1 "One True Flag"**
(варбонд *Masters of Ceremony*) с флага Супер-Земли на **флаг Республики
Казахстан** — голубое полотнище, золотое солнце с 32 лучами, парящий беркут и
национальный орнамент «кошкар-мюиз» у древка.

> Мод чисто клиентский и визуальный: другие игроки его не видят, на геймплей он
> не влияет. Официальной поддержки модов у Arrowhead нет — используйте на свой
> страх и риск и удаляйте патч-файлы перед отправкой баг-репортов.

## Структура репозитория

```
textures/                  # готовые текстуры флага (PNG)
  kz_flag_4096x2048.png    #   родные пропорции флага 2:1
  kz_flag_2048x1024.png
  kz_flag_2048x2048.png    #   растянутый вариант под квадратные UV
  kz_flag_1024x1024.png
tools/
  generate_flag.py         # генератор текстур (Python + Pillow), всё рисуется кодом
```

Текстуры — стилизованная отрисовка флага (не официальный векторный эталон),
но с корректными официальными цветами: голубой `#00AFCA`, золотой `#FEC50C`.
Перегенерировать можно так:

```bash
pip install pillow
python3 tools/generate_flag.py
```

## Пошаговая сборка мода

### 1. Найдите архив с ассетами CQC-1

Игровые ассеты лежат в `steamapps/common/Helldivers 2/data` в виде архивов с
хеш-именами (`9ba626afa44a3aa3` и т.п.). В аддоне HD2SDK есть поиск по
человекочитаемым именам (Archive Spreadsheet у сообщества тоже помогает):
ищите по `flag`, `cqc1` или названию варбонда. После обновлений игры ID могут
меняться — при необходимости ищите заново.

### 2. Экспортируйте оригинальную текстуру полотнища

В HD2SDK загрузите архив, найдите материал полотнища флага и экспортируйте его
**base color** текстуру (ПКМ → Save Texture → PNG/DDS). Запомните:

- разрешение оригинала (например 2048×2048);
- формат сжатия (обычно BC1/BC7 — аддон показывает при экспорте);
- раскладку UV (полотнище может занимать не весь квадрат текстуры).

### 3. Подгоните флаг под UV-раскладку

Если полотнище занимает всю текстуру — просто возьмите готовый файл из
`textures/` подходящих пропорций. Если UV нестандартный, откройте
экспортированный оригинал в редакторе (GIMP/Photoshop/Krita) как подложку и
вставьте флаг из `textures/` поверх нужной области. Учтите, что на обратной
стороне полотнища текстура может отражаться зеркально.

### 4. Сконвертируйте PNG → DDS

Формат и разрешение должны совпадать с оригиналом. Пример для BC7 с полной
цепочкой мипмапов (Windows):

```bat
texconv -f BC7_UNORM -m 0 -y kz_flag_2048x2048.png
```

Для BC1 замените `-f BC7_UNORM` на `-f BC1_UNORM`.

### 5. Импортируйте текстуру и соберите патч

В HD2SDK: ПКМ по той же текстуре → **Import Texture** (выберите ваш DDS) →
**Patch → Write Patch**. Аддон создаст рядом файлы вида:

```
<archive_id>.patch_0
<archive_id>.patch_0.gpu_resources
<archive_id>.patch_0.stream
```

### 6. Установите мод

- **Через мод-менеджер:** запакуйте патч-файлы в zip и добавьте в менеджер.
- **Вручную:** скопируйте патч-файлы в `steamapps/common/Helldivers 2/data`.
  Для удаления мода просто удалите их — оригинальные архивы не трогаются.

Запустите игру, возьмите CQC-1 One True Flag и несите флаг Казахстана сквозь
ряды автоматонов. Алға, Қазақстан! 🦅

## Известные ограничения

- После патчей игры архив может получить новый ID — патч перестанет
  подхватываться, потребуется пересборка (шаги 1 и 5).
- На флаге, вероятно, есть отдельные текстуры normal/ORM — их можно не трогать,
  тканевый рельеф Супер-Земли слегка «просвечивает» через новый цвет; при
  желании нормал-мапу можно заменить нейтральной.
