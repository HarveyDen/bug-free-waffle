# Выгрузка заявлений с elicense.kz

Скрипт `download_zayavleniya.py` заходит на портал [elicense.kz](https://elicense.kz)
под несколькими логинами по очереди, обходит раздел **«Мои заявления»**
(`/LicensingContent/SimpleSearchRequest`) постранично и складывает PDF по каждому
заявлению в **одну общую папку «Заявления» на рабочем столе**. Без подпапок и
сортировки — всё в один каталог, как и просили.

Файлы называются так же, как их отдаёт портал, например
`Request_KZ34VAY01155228_df.pdf`.

## Что нужно один раз поставить

1. **Python 3.8+** — [python.org/downloads](https://www.python.org/downloads/)
   (на Windows при установке отметьте галочку *Add Python to PATH*).
2. **Chrome** — обычный, который у вас уже стоит.
3. Библиотеку управления браузером:

   ```bash
   pip install playwright
   playwright install chromium
   ```

   Вторая команда нужна как запасной вариант: если системный Chrome не найдётся,
   скрипт возьмёт встроенный Chromium.

4. Для входа по ЭЦП портал требует запущенный **NCALayer** — как обычно, вручную.

## Шаг 1. Завести профили и войти в каждый

Каждый логин — отдельный профиль браузера со своими cookie. Придумайте им любые
имена (латиницей), например по владельцу ЭЦП:

```bash
python3 download_zayavleniya.py setup ivanov petrov ktransgroup
```

Скрипт откроет окно Chrome для первого профиля и будет ждать. Вы входите на
портал как обычно (ЭЦП через NCALayer либо логин/пароль). Как только вход
выполнен, скрипт это замечает сам и предлагает перейти к следующему профилю —
нажмите Enter.

Пока вы вводите пароль или подписываете ЭЦП, скрипт **не трогает вашу вкладку**:
он проверяет вход фоновым запросом, чтобы ничего не сбить.

Cookie сохраняются в `~/.elicense_downloader/profiles/<имя>` и живут между
запусками — повторно входить нужно, только когда портал разлогинит сессию.

Посмотреть, что уже заведено:

```bash
python3 download_zayavleniya.py list
```

## Шаг 2. Скачивание

```bash
python3 download_zayavleniya.py run
```

Скрипт по очереди пройдёт по всем профилям, обойдёт все страницы списка и
скачает всё, чего ещё нет на диске. Прогресс виден в консоли:

```
[12:03:11]   Мои заявления: страниц 1463, обрабатываем 1–1463
[12:03:12]   Стр. 1/1463: заявлений 10
[12:03:13]     KZ34VAY01155228 → Request_KZ34VAY01155228_df.pdf
```

Запуск можно прервать (Ctrl+C) и продолжить позже — уже скачанное второй раз не
качается.

### Регулярная выгрузка

Чтобы новые заявления подтягивались сами, оставьте скрипт работать в режиме
наблюдения — проверка каждые 30 минут:

```bash
python3 download_zayavleniya.py run --watch 30
```

Повторные проходы короткие: встретив 30 подряд уже скачанных заявлений, скрипт
понимает, что новых выше по списку нет, и переходит к следующему профилю.

## Полезные ключи

| Ключ | Зачем |
|---|---|
| `-p ivanov` | только один профиль (можно повторять: `-p ivanov -p petrov`) |
| `--since 01.08.2026` | брать только заявления не старше даты |
| `--pages 1-20` | ограничить диапазон страниц списка |
| `--limit 50` | остановиться после 50 новых файлов на профиль |
| `--out "D:\Архив"` | другая папка вместо «Заявления» на рабочем столе |
| `--lang kz` | документы на казахском |
| `--delay 2` | пауза между скачиваниями, сек (по умолчанию 1.2) |
| `--stop-after-known 30` | ускорить регулярный запуск (см. выше) |
| `--full-scan` | наоборот, всегда проходить весь список целиком |
| `--redownload` | перекачать даже то, что уже есть |
| `--include-pending` | плюс список «требующих действий пользователя» |
| `--headless` | без окна браузера (только если вход уже выполнен) |
| `--unattended` | не ждать ручного входа: профиль без сессии пропускается |
| `--chrome-path ...` | путь к Chrome, если он стоит нестандартно |

Полный список: `python3 download_zayavleniya.py run --help`.

## Как это работает

По каждому заявлению из списка берётся его номер (`KZ…`) и внутренний `id`, после
чего PDF запрашивается у портала напрямую, по тем же адресам, которые использует
сама страница заявления. Источники пробуются по очереди, берётся первый
сработавший:

1. `/Handlers/DataFormHandler.ashx?id=<id>&lang=ru` — форма сведений
   (именно так получен образец `Request_KZ34VAY01155228_df.pdf`);
2. `/Requests/GetFileListByRequest` → `/Requests/GetFileRequestByLanguage/<id>` —
   файл заявления;
3. `/Requests/SaveRequestPageAsPdf?requestId=<id>` — печатная версия страницы.

Можно зафиксировать один источник: `--source df`.

Если ни один не отдал PDF, заявление помечается ошибкой в логе и будет
переспрошено при следующем запуске — остальные при этом качаются дальше.

## Где что лежит

```
<Рабочий стол>/Заявления/        только PDF, одним списком
~/.elicense_downloader/
    profiles/<имя>/              cookie профилей (это и есть «логины»)
    state.json                   что уже скачано
    index.csv                    реестр: номер, дата, статус, имя файла
    log.txt                      подробный лог
```

Служебные файлы намеренно лежат отдельно, чтобы в папке «Заявления» не было
ничего, кроме самих PDF.

Дубли не плодятся: если одно заявление видно сразу из нескольких логинов, файл
скачивается один раз. Если удалить файл из папки — при следующем проходе он
скачается заново.

## Если что-то пошло не так

**«Профиль … : нужен вход»** — сессия портала истекла. Запустите
`setup <имя>` и войдите заново.

**«не скачано (df: HTTP 404; …)»** — по этому заявлению портал не отдаёт
документ (часто так с черновиками и отозванными). Запись останется в
`index.csv` и в логе, при следующем проходе попытка повторится.

**Chrome не запускается** — укажите путь явно:
`--chrome-path "C:\Program Files\Google\Chrome\Application\chrome.exe"`.

**Портал отвечает медленно / рвёт соединение** — увеличьте паузу: `--delay 3`.
Каждый файл и так запрашивается с тремя попытками и нарастающей задержкой.

## Использование своих профилей Chrome

Если вы уже вошли в порталы в обычном Chrome и хотите использовать те же
профили, закройте Chrome полностью и запустите:

```bash
python3 download_zayavleniya.py run \
  --user-data-dir "C:\Users\<вы>\AppData\Local\Google\Chrome\User Data" \
  --profile-directory "Profile 1"
```

Так можно работать только с одним профилем за раз, и Chrome в это время должен
быть закрыт — поэтому по умолчанию используется отдельный набор профилей.
