# Telegram-бот для построения маршрутов (Google Maps + Яндекс Карты)

Бот принимает две точки — А и Б (например, `Алматы - Астана`), строит автомобильный
маршрут и отвечает:

- 📏 **расстоянием в километрах**;
- ⏱ примерным временем в пути;
- 🏙 **списком городов и населённых пунктов, через которые проходит маршрут**;
- 🔗 ссылкой на маршрут на сайте Google Maps / Яндекс Карт.

Можно выбрать один сервис или сравнить оба сразу.

## Пример

> **Вы:** `Алматы - Астана`
>
> **Бот:** Какими картами построить? 🌍 Google / 🗺 Яндекс / ⚖️ Сравнить обе
>
> **Бот:**
> ```
> Google Maps
> 🚗 Алматы, Казахстан → Астана, Казахстан
> 📏 Расстояние: 1211 км
> ⏱ В пути: ~14 ч 30 мин
> 🏙 Через населённые пункты:
> Алматы → Қонаев → Сарыөзек → Талдыкорган → Уштобе → Балхаш → Караганда → Темиртау → Астана
> 🔗 Открыть маршрут на карте
> ```

## Как это работает

1. Точки А и Б геокодируются в координаты.
2. Сервис карт (Google Directions API или Яндекс Маршрутизатор) строит
   автомобильный маршрут и возвращает его геометрию и длину.
3. Вдоль геометрии маршрута берутся точки примерно каждые 25 км
   (но не более ~30 точек), и каждая обратным геокодированием превращается
   в название населённого пункта. Повторы убираются — получается цепочка
   городов по пути.

## Установка

Нужен Python 3.10+.

```bash
cd route-bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и заполните ключи
python bot.py
```

## Ключи API

Заполните файл `.env` (см. `.env.example`):

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Напишите [@BotFather](https://t.me/BotFather) → `/newbot` |
| `GOOGLE_MAPS_API_KEY` | [Google Cloud Console](https://console.cloud.google.com/apis/credentials): создайте ключ и включите **Directions API** и **Geocoding API** (нужен биллинг-аккаунт, есть бесплатный лимит) |
| `YANDEX_GEOCODER_API_KEY` | [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/services): API «JavaScript API и HTTP Геокодер» |
| `YANDEX_ROUTER_API_KEY` | Там же: API «Distance Matrix API и Маршрутизация» (Маршрутизатор) |

Можно указать ключи только одного сервиса — тогда бот будет работать только с ним.
Обратите внимание: у обоих сервисов есть квоты; на каждый маршрут расходуется
1 запрос маршрутизации и до ~30 запросов обратного геокодирования.

## Использование

- `Алматы - Астана` — просто сообщением;
- также понимает `Москва — Санкт-Петербург`, `Алматы -> Шымкент`, `Алматы → Тараз`
  и две строки (А на первой, Б на второй);
- `/route Алматы - Астана` — то же самое командой;
- `/help` — справка.

Дефисы внутри названий не ломают разбор: `Усть-Каменогорск - Семей` работает.
